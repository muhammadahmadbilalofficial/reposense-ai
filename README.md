# 🚀 RepoSense AI

**Developer Onboarding & Code Quality Intelligence Dashboard**

RepoSense AI is an intelligent developer tool that inspects GitHub repositories in real time. It analyzes language breakdowns, tracks essential onboarding documentation, and conducts code hygiene checks to speed up onboarding for engineering teams.

---

### 🌐 Live Demo
🔗 **Try it here:** [https://reposense-ai-nine.vercel.app](https://reposense-ai-nine.vercel.app)

---

## ✨ Features

- **⚡ Real-time GitHub Inspection:** Scan any public GitHub repository directly via URL using GitHub's REST API.
- **📊 Language Breakdown:** File counts, lines of code, and tech stack distribution.
- **📋 Onboarding Checklist:** Instant verification for essential repo standards (`README.md`, `.gitignore`, `requirements.txt`, licenses, Docker setup, etc.).
- **🛡️ Code Hygiene & Smells:** Surface security indicators and project health metrics.
- **📱 Fully Responsive:** Optimized for both desktop and mobile screens.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router, Serverless API Routes)
- **Language:** TypeScript, Python logic architecture
- **Styling:** Tailwind CSS / Modern Dark UI
- **Hosting:** Vercel

---

## 🚀 How to Use

1. Visit the [Live Dashboard](https://reposense-ai-nine.vercel.app).
2. Paste any public GitHub repository URL (e.g., `https://github.com/owner/repository`).
3. Click **Scan** to view instant repository analytics and onboarding health.
